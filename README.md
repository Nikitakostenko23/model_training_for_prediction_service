# Прогнозирование осложнений после каротидных реваскуляризаций

## Описание задачи

Пациенты с гемодинамически значимым стенозом внутренней сонной артерии (ВСА) являются кандидатами на выполнение одного из четырёх типов оперативных вмешательств:

- **КАС** - каротидная ангиопластика со стентированием (эндоваскулярное вмешательство)
- **КЭЭ классическая** - классическая каротидная эндартерэктомия
- **КЭЭ эверсионная** - эверсионная каротидная эндартерэктомия
- **КЭЭ гломуссохраняющая** - гломуссохраняющая каротидная эндартерэктомия

Независимо от типа вмешательства, процедуры сопряжены с риском периоперационных осложнений, включая ишемический инсульт, транзиторную ишемическую атаку (ТИА), гиперперфузионный синдром, тромбоз стента, острый инфаркт миокарда, гематому в месте доступа и острую почечную недостаточность.

**Цель проекта:** разработка и сравнение моделей машинного обучения для прогнозирования риска осложнений на основе клинических и инструментальных данных.

> Данный репозиторий предназначен для **демонстрации результатов обучения моделей**, используемых в основном проекте [`prediction_system_backend`](https://github.com/Nikitakostenko23/prediction_system_backend).
## Данные

Исходный набор данных был предоставлен одной из медицинских организаций (больниц). **В силу конфиденциальности и внутреннего регламента лечебного учреждения, набор данных не может быть опубликован.** Это означает, что результаты, представленные в данном репозитории, являются демонстрационными, и **воспроизвести обучение моделей на исходных данных сторонним пользователям невозможно**.

## Методы уменьшения размерности и отбора признаков

Для повышения обобщающей способности моделей исследуется влияние трёх методов:

1. **PCA (Principal Component Analysis)**  
   Линейное преобразование, сохраняющее максимальную дисперсию данных. Число компонент выбирается по критерию 95% объяснённой дисперсии.

2. **LDA (Linear Discriminant Analysis)**  
   Проекция на подпространство, максимизирующее разделимость классов (для бинарной задачи – на одну ось).

3. **SBS (Sequential Backward Selection)**  
   Жадный алгоритм исключения признаков, оценивающий качество модели (ROC-AUC) на кросс-валидации после каждого удаления.

Каждый метод применяется к одним и тем же исходным данным независимо, с возвратом к исходной матрице признаков перед каждым преобразованием.

## Классификаторы

Для каждого варианта предобработки обучаются следующие модели:

- Логистическая регрессия (LogisticRegression)
- k-ближайших соседей (KNeighborsClassifier)
- Метод опорных векторов (SVC)
- Случайный лес (RandomForestClassifier)
- AdaBoost (AdaBoostClassifier)
- XGBoost (xgb.XGBClassifier)
- Многослойный персептрон (KerasClassifier / Sequential)

## Оценка качества

- **Тестовая выборка:**  
  - 30% данных для первых 6 моделей  
  - 15% для MLP
- **Метрики:**  
  `accuracy`, `precision`, `recall`, `F1-score (macro и weighted)`, `ROC-AUC`, `MCC` (Matthews correlation coefficient)

## Подбор гиперпараметров

- **Основной метод:** `GridSearchCV`  
- **Дополнительный (для ансамблей и SVM):** `HalvingGridSearchCV` (применялся в случаях длительных вычислений)

## Валидация

- **Классическое машинное обучение:** стратифицированная кросс-валидация с 5 фолдами, разбиение на обучающую и тестовую выборки 70:30.
- **Нейронные сети:** стандартное разбиение на обучающую, валидационную и тестовую выборки в соотношении 70:15:15 с созданием искусственных синтетических примеров (data augmentation) и балансировкой классов (SMOTE).
